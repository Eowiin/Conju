# Conju

A Spanish conjugation trainer for French, English, and Portuguese speakers. Runs entirely in the browser — no backend, no dependencies.

## Features

- ~160 verbs (regular and irregular)
- 14 tenses: present, preterite, imperfect, perfect, pluperfect, future, periphrastic future, future perfect, conditional, conditional perfect, present/imperfect subjunctive, imperative, gerund
- Every expected answer comes from a verified conjugation table (see below)
- Accents and ñ count. An answer that is right except for accents gets a second try ("Almost: check the accents"); case and extra spaces are ignored
- Alternative forms are accepted and shown ("Also accepted": -se imperfect subjunctive, RAE 2010 spellings such as *rio* / *rió*)
- Accented letter bar under the input (á é í ó ú ñ ü)
- Grammar rule explanations computed for each verb and tense, with the verb's own forms
- Full conjugation table shown on correction
- Anti-repetition system, score and streak tracking
- Interface in French, English, and Portuguese

## The conjugation table

`js/conjugations.js` is generated by `tools/build_table.py`. It holds, for each verb, its `type` (ar/er/ir), its forms in every tense (`t`: six cells per tense, `null` for the imperative yo, `"a|b"` when several forms are accepted — the first one is the reference; gerund and participle are single strings) and its `rules`.

### Sources

A cell (verb, tense, person) enters the table only when **two independent sources give the same form**:

1. **verbecc** (`pip install verbecc`, rule-based conjugator).
2. **Fred Jehle's Spanish verb database**, downloaded on first run to `tools/cache/` (not in the repo). It is licensed CC BY-NC-SA: it is used to check the table, not published with it.
3. **Analogy with a model verb** from Jehle, for verbs Jehle lacks or verbecc mishandles (cantar/pasar ← hablar, discutir/existir/dividir ← vivir, poseer ← leer, concluir ← construir, gobernar/despertar/confesar ← pensar, comprender ← comer, doler/llover ← mover). Forms are transposed on the last vowel of the stem: *pienso → gobierno*, *leyó → poseyó*.
4. For the past participle only, the **regular rule** (-ado, -ido, -ído after a/e/o): verbecc often returns the adjectival participle (*despierto*, *confeso*, *diviso*…).

If no pair of sources agrees, the build stops and lists the cells.

Compound tenses (perfect, pluperfect, future perfect, conditional perfect) and the periphrastic future are not read from any source: they are built from the verified participle and the verified forms of *haber* and *ir*. The -se imperfect subjunctive is derived from the -ra form and accepted as an alternative.

### Overrides

Hand decisions live in `tools/overrides.json`, each with a mandatory `reason`. Key `verb/tense/person` for one cell, or `verb/tense` with six forms. Current decisions:

| Cell | Form | Why |
|---|---|---|
| haber (all tenses) | he, has, ha\|hay… ; imperative *he* | not in Jehle, no model verb: entered by hand |
| valer, imperative tú | vale | verbecc gives the archaic *val* |
| obtener / contener, imperative tú | obtén / contén | verbecc drops the accent |
| huir, preterite yo | hui\|huí | RAE 2010 spelling first, older one accepted |
| huir, present vosotros | huis\|huís | idem |
| reír, preterite él | rio\|rió | idem |
| reír, subjunctive vosotros | riais\|riáis | idem |

The build also reports overrides that have become moot (sources now agree with them) or that match no cell.

### Rules

For each verb and tense, the build works out which rule explains the forms (regular, -zco, -go, g → j, -uir, stem change e → ie / o → ue / e → i / u → ue, strong preterite, i → y, irregular future stem, subjunctive from the present yo form, imperfect subjunctive from the preterite 3rd person plural, imperative person by person…) and stores its id with the verb's real forms as parameters. `js/rules.js` only words them in the three languages. A verb/tense the build cannot explain (ser, ir, estar in the present…) gets an "irregular, memorise" rule and is listed at the end of the build.

### Adding a verb

```bash
python3 -m venv tools/.venv
tools/.venv/bin/pip install -r tools/requirements.txt
echo "nuevo_verbo" >> tools/verbs.txt
tools/.venv/bin/python tools/build_table.py
node tests/check.js
```

If the build stops on disagreeing cells, check the forms in a reference (RAE, a good conjugator), then either add the verb to `ANALOGY` in `build_table.py` with a model verb from Jehle, or add an entry to `tools/overrides.json` with a reason. Commit `tools/`, `data/conjugations.json` and `js/conjugations.js` together.

## Size and compression

`js/conjugations.js` weighs about 450 KB (about 60 KB gzipped). Make sure nginx compresses JavaScript — `text/html` is the only type compressed by default:

```nginx
gzip on;
gzip_types application/javascript;
```
